# Mindhall logo files

The logo is five dots joined by one line, forming an M: several AIs sharing one mind.

## Which file to use

| Where | File |
| --- | --- |
| On a dark background | `logo/mindhall-logo-white.svg` |
| On a light background | `logo/mindhall-logo-black.svg` |
| Where there's no room for the name | `mark/mindhall-mark-white.svg` (or `-black` on light) |
| App icon | `icon/mindhall-icon-1024.png` |
| Profile picture (X, Discord, GitHub, Product Hunt) | `icon/mindhall-profile-1024.png` |
| Browser tab and phone home screen | the files in `favicon/` |

Every logo and mark comes as an SVG and a PNG with the same name. Use the SVG where you can: it stays sharp at any size.

## Colours

| Name | Value | Used for |
| --- | --- | --- |
| Black | `#0A0A0C` | Backgrounds, and the logo on light backgrounds |
| White | `#F6F4EF` | The logo and text on black |

## Font

Inter Bold, with letter-spacing of -0.035em. In the logo files the name is drawn as shapes, so no font needs to be installed.

## Good to know

- There's no brand colour: the logo is white on dark backgrounds and black on light ones.
- The favicon uses a slightly heavier mark, so it stays readable at 16 pixels.
